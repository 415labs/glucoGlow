GlucoGlow

A dim, bedside glucose display for the ESP32-C3 0.42″ OLED board. Flash it from this page; there is nothing to install.

This browser can't flash devices. Please open this page in Chrome, Edge or Brave on a Windows, Mac or Linux computer. Flashing needs a secure (https) page. Please use the official link from the project page.
Firmware version __VERSION__

Steps

  1. Use Chrome, Edge or Brave on a computer (not Safari, Firefox or a phone).
  2. Plug the board into your computer with a USB cable that carries data (some cables only charge).
  3. Click Connect & install, choose the USB device in the list (often named USB JTAG/serial or USB Serial), then click Install.
  4. Wait about 30 seconds. When it finishes the board restarts and its screen shows SETUP HOW-TO.
  5. Follow the on-screen steps: join the GlucoGlow-setup WiFi with the password shown on the screen, then enter your home WiFi and LibreLinkUp details in the page that opens.

If the board isn't listed

  1. Unplug it. Hold the BOOT button, plug it in while holding, then release. Click Connect again.
  2. Try another USB cable or port; avoid hubs.
  3. Close other programs that might use the port (Arduino IDE, serial monitors).
Updating later

Run this page again; your settings (WiFi, LibreLinkUp login, ranges) are kept. To start fresh, use Factory reset in the device's web page.

Not a medical device. GlucoGlow is a convenience display. It uses the unofficial LibreLinkUp service, which can change or stop working without notice. Always keep your official CGM alerts turned on, and do not use this to make treatment decisions.
